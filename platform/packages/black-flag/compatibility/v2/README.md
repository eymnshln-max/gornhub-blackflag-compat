# Compatibility module v2

`BlackFlagCompatibility.dylib` is the player-tested x86-64 macOS module. It repairs missing color attachment state and suppresses the measured SDR/HDR corrupt pause overlay.

See the repository [installation guide](../../../../../docs/INSTALLATION.md), [code/build guide](../../../../../docs/CODE.md) and [case study](../../../../../docs/CASE_STUDY.md). The manifest pins the exact supported renderer and module. Source files are preserved verbatim from the tested package.
